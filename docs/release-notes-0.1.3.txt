Yiuk Device Assist 0.1.3
========================

新增
- 远程协助活动面板改为独立进程 yiuk-activity-panel.exe：
  原生 Win32 逐像素透明悬浮窗口，自行绘制圆角卡片与柔和阴影，
  右上角提供 最小化 / 全屏 / 关闭 三个按钮。
- 面板只显示当前会话，并按操作类型给文字着色（参考 pi 的深色主题）：
  读取=蓝、执行命令=绿、下载=兰紫、输出=灰、错误=红、会话与完成=紫/绿。
- 面板可随时关闭、随时重新打开：关闭不影响会话；
  新操作只更新已打开面板的内容，不会把它弹到前台或抢焦点。
- 面板支持拖动、边缘缩放、滚轮滚动、贴底自动跟随，
  并记住上次的位置与尺寸。

变化
- 移除旧的「远程协助活动」对话框（含会话切换器和「断开会话」按钮）。
  断开远程控制请用主页「活跃会话」卡片上的「立即停止会话」，或托盘菜单。

安装 / 升级
- Windows 10/11 x64。解压后目录内需同时存在：
  yiuk-device-assist.exe、yiuk-activity-panel.exe、yiuk-mcp.exe 与 Qt 运行库。
- 直接覆盖旧版本目录即可；配置与凭证保存在
  %LOCALAPPDATA%\Yiuk\DeviceAssist（旧的 %APPDATA% 目录仍会被读取）。
- 若提示「信息面板无法启动」，说明安装目录缺少 yiuk-activity-panel.exe。

启动
1. 运行 yiuk-device-assist.exe。
2. 设置 → 平台服务：填写服务器地址（TLS 端口）与 player 密码。
3. 自签名服务器：首次连接会显示证书 SHA-256 指纹，
   确认是自己的服务器后再选择「信任此证书」。
4. 设置 → Agent 集成 → 复制 Agent 配置，粘贴到 Agent 的 MCP 配置中。

查看远程协助过程
- 会话进行中：主页「活跃会话」卡片 → 「查看活动」。
- 任何时候：托盘图标右键 → 「打开远程协助活动」。
