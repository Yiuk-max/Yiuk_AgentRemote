Yiuk Device Assist 0.1.8
======================

本版重点：Agent 可以在远程会话中直接向设备所有者提问。

新功能
------
- ask_user / get_user_reply：Agent 在已授权会话中弹出一个询问窗口，给出最多 6 个选项，
  同时始终允许用户自行输入回答。
  * 点击选项即为回答；也可以输入后点“发送”或按 Enter。
  * “暂不回答”、关闭窗口、Esc 都返回 cancelled，绝不自动选择任何一项。
  * 窗口与客户端现有风格一致，不阻塞主窗口，可随时从主窗口停止会话。
  * 客户端在托盘后台时会置顶显示并发出托盘提醒，避免被其它应用遮住。
  * 明确区分 answered / cancelled / timed_out / result_unknown，断线不会被当成拒绝。

界面
----
- 去掉页面标题下的概括性说明、重复的设备码卡片、重复的平台状态文字。
- 弹窗与提示文案精简，只在涉及权限、密码和不可恢复操作时保留说明。
- 统一浅色细滚动条。
- 询问窗口、活动面板、托盘都使用新的品牌图标；托盘为独立绘制的简化图标，
  16px 下仍可辨认。

其它
----
- 修正：空输入按 Enter 不再误选第一项；标题栏按钮不再成为弹窗的隐式默认按钮。
- 修正：长问题只滚动正文，输入框和按钮始终可见；窗口不会越出可用屏幕。

升级说明
--------
- 需要平台 core / gateway 一起升级（新增用户询问消息），网关只是透明转发。
- MCP 工具数从 14 增加到 16，Agent 侧需要重新加载 MCP Server 才会看到新工具。
- 卸载不会删除 %LOCALAPPDATA%\Yiuk\DeviceAssist，重装沿用同一设备身份。
