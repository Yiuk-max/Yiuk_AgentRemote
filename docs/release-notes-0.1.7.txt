Yiuk Device Assist 0.1.7
========================

设备身份
- 设备码发生冲突时由平台重新分配，客户端自动接受新码并提示一次；
  不再出现“平台上的码属于别人、本机一直连不上”的死局。
- 本机身份合并到单个 identity.json（设备码 + 临时密码 + 平台连接参数），
  写入走临时文件 + 重命名，避免崩溃时出现“新码配旧密码”。
- 旧版 %LOCALAPPDATA%\Yiuk\DeviceAssist\device.json 与 platform.json 会在首次
  启动时自动迁移，原文件保留一版；%APPDATA% 下的旧目录同样支持读取。
- 修正配置文件损坏或不可写时“每次启动都生成新设备码”的问题；写入失败现在会记日志。

平台连接
- 平台限流（RATE_LIMITED）改为退避重试，不再当作永久错误。
  服务端重启或同一出口 IP 上多台设备同时重连时，客户端会自己恢复。

服务端配套
- 本客户端依赖新版平台：设备码冲突时分配新码、墓碑保留与 reclaim、
  未使用设备回收、注册限流（register_rate_per_min / unused_device_release_sec）。
  请同时升级服务端，否则新客户端仍按旧行为工作。

安装 / 升级
- Windows 10/11 x64，解压即用：目录内同时有 yiuk-device-assist.exe、
  yiuk-activity-panel.exe、yiuk-mcp.exe 与 Qt 运行库。
- 覆盖旧目录即可；本机凭证保留在
  %LOCALAPPDATA%\Yiuk\DeviceAssist，首次启动时迁移为 identity.json。
